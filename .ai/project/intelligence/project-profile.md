## Known Patterns & Anti-Patterns

### Patterns to Follow
1. **PublicIdTrait on all entities**: Every new entity must use PublicIdTrait (except join tables)
2. **CustomerScopedEntityInterface**: Any entity with customer_id must implement this interface
3. **DTOs with fromArray()**: API inputs validated via DTO with Symfony Validator constraints
4. **ApiErrorResponder for errors**: All API error responses use the centralized responder
5. **Enum for bounded values**: Use PHP enums for status fields, role types, etc.
6. **Immutable events**: ShipmentEvent and AuditLog are append-only

### Anti-Patterns to Avoid
1. **Exposing internal IDs**: Never use BIGINT id in APIs or URLs — always publicId (ULID)
2. **Direct DB in controllers**: Use repositories, never raw EntityManager in controllers
3. **Symfony 8.x packages**: Blocked by composer — respect the 7.4 LTS lock
4. **XML/YAML Doctrine mapping**: Only attribute-based mapping is allowed
5. **Skipping tenant filter**: All customer-scoped data must respect the Doctrine SQL filter
