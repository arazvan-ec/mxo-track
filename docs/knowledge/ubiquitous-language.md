## customer-management

- **Customer** — aliases: cliente, client
  Empresa o persona que recibe entregas; tenant principal del sistema multi-tenant.

- **DeliveryZone** — aliases: zona de entrega, zone
  Polígono geográfico que agrupa CustomerLocations para optimización de rutas.

## delivery-execution

- **Pod** — aliases: POD, proof of delivery, evidencia de entrega, ProofOfDelivery
  Comprobante (foto, firma, geolocalización) que valida la entrega completa de un RouteStop.

## fleet-management

- **Driver** — aliases: conductor, chofer, operator
  Persona que ejecuta una Route conduciendo un Vehicle.

- **Vehicle** — aliases: vehículo, vehiculo, fleet_unit, truck
  Unidad física que transporta entregas y reporta posición vía GPS.

## gps-tracking

- **VehiclePosition** — aliases: posición de vehículo, GPS position, snapshot
  Posición geográfica reportada por un Vehicle vía Traccar (lat, lng, timestamp, speed).

## notifications

- **Notification** — aliases: notificación, notificacion, alert
  Mensaje saliente (SMS, WhatsApp, push, email) hacia un usuario o destinatario.

## realtime

- **RealtimeEvent** — aliases: evento realtime
  Mensaje publicado vía Mercure/SSE para actualizar UIs conectadas (positions, route updates, alerts).

## route-planning

- **Route** — aliases: ruta, tour, route_plan
  Plan de entregas asignado a un conductor para una jornada.

- **RouteStop** — aliases: parada, stop, waypoint, delivery_stop
  Una entrega individual dentro de una Route, con cliente, dirección, y ventana horaria.

- **RouteSnapshot** — aliases: snapshot, instantánea de ruta
  Estado materializado de una Route en un momento dado, usado para read-models y replay.

- **RouteEventType** — aliases: tipo de evento de ruta
  Enum de tipos de RouteEvent (15 cases: route_started, stop_delivered, deviation_detected, etc.).

- **RouteEvent** — aliases: evento de ruta, route_event
  Evento de dominio que documenta una transición de estado en una Route (started, paused, completed, etc.).

- **RouteStatus** — aliases: estado de ruta
  Enum de estados de una Route (pending, in_progress, completed, cancelled).

- **RouteStopStatus** — aliases: estado de parada
  Enum de estados de un RouteStop (pending, arrived, delivered, skipped, exception).

## security

- **User** — aliases: usuario, operador
  Persona autenticada que opera el sistema; pertenece a un Customer (multi-tenant).

## shipment-management

- **ParcelStatus** — aliases: estado de paquete

- **Parcel** — aliases: paquete, package
  Unidad física individual transportada dentro de un Shipment.

- **ShipmentEvent** — aliases: evento de envío
  Evento de dominio que registra una transición de estado de un Shipment.

- **ShipmentPriority** — aliases: prioridad de envío

- **Shipment** — aliases: envío, envio, delivery
  Solicitud de entrega de paquetes desde un origen a un destino, asignable a una Route.
