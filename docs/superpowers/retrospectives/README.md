# Retrospective Reviews

Reviews periódicos del sistema de feedback para cerrar el learning loop.

## Cadencia

- **Mensual:** Review de execution logs del mes. Analizar estimate accuracy, blockers, patterns.
- **Trimestral:** Review estratégico. Analizar métricas de negocio, decisiones arquitectónicas, actualizar knowledge modules.

## Proceso

1. Recopilar datos: execution logs + `app:learning:metrics --period=30d`
2. Usar template: `docs/superpowers/templates/retrospective-review-template.md`
3. Escribir review en este directorio: `YYYY-MM-review.md`
4. Actuar: actualizar docs/knowledge/ y CLAUDE.md con lecciones
